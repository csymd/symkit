# Product harness

Specs, roadmap, and shipping notes. Brand and voice live in the **creative**
harness.

```bash
./cli/symkit init /path/to/new-product \
  --harness product --role product-manager --scaffold
```

Roles: `product-manager` (`pm`), `materials`.

Written PRD and roadmap are the source of truth. Do not invent metrics.

One harness per target. To attach creative packs, pass `--also` on purpose.
