# Course preparation (agent pointer)

**Instructor only** (`instructor` package). TAs must not use course-prep.

activities, or preparing private instructor notes, use:

  an explicit decision.
- Align student-facing AI language with `docs/ai-what-to-expect.md`.
- Install only locally; do not commit this pack to public course branches.
