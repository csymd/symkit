# Docs

Written science lives here (aims, protocol, statistical analysis plan).
These documents are the source of design truth for agents.

Copy blanks with:

```bash
symkit install . --harness research --role researcher --docs aims --docs protocol
```

Prefer `docs/aims.md` and `docs/protocol.md` (or the same names under
`documents/`). Do not duplicate aims that already live in the protocol.
