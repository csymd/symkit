# Contributing

- Author on `develop` (or a feature branch); keep `main` stable.
- Prefer annotated tags for scientific milestones, not fake software releases.
- Do not commit restricted data or secrets.
- Each workstream directory should have a short README (purpose, inputs,
  outputs, assumptions). Use `analysis/<workstream>/` when starting empty;
  keep the repo’s existing code tree if one is already here.
